# 🐍 Snake Game

A classic Snake Game project built with **Python & Pygame**.

This project was developed as part of a programming exercise on **Quera**, with a focus on practicing Python, Object-Oriented Programming, game logic, and working with an existing project structure.

> **Note:** This was an educational project. Some parts of the project structure and base code were provided as part of the exercise, while the required sections were implemented and completed by me.

---

## 🎮 Features

* 🐍 Snake movement
* 🍎 Fruit generation and collection
* 🧱 Obstacles / blocked cells
* 💥 Collision handling
* 🔄 Screen wrapping
* ⌨️ Configurable controls
* 🕹️ Turn-based game management
* 🧩 Object-oriented design

---

## 🛠️ Built With

* **Python**
* **Pygame**
* Object-Oriented Programming
* JSON
